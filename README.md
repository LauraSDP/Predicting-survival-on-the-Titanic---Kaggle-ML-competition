# Predicting-survival-on-the-Titanic---Kaggle-ML-competition

This repository contains a Python notebook implementing a simple classification machine learning model (Random Forest) to predict survival on the Titanic (popular Kaggle ML competition). The dataset is available on Kaggle. 

The notebook was originally developed and published on Kaggle. 

## Structure 
- 'predicting-survival-on-the-titanic-ml.ipynb': main notebook containing the data analysis and the model
